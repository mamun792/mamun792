## 📐 Architecture Philosophy

```
Request → Controller → Service → Repository → Database
                           ↓
               Validation → DTO → Response Resource
```

| Principle | Practice |
|---|---|
| 🔐 **Security First** | Auth, input validation & rate limiting on every endpoint |
| 🧱 **Clean Architecture** | Strict layer separation — no logic leaking into controllers |
| ⚡ **Performance** | EXPLAIN-driven indexing, Redis caching with clear invalidation |
| 🔁 **Idempotency** | Mandatory for payments & all critical write operations |
| 🧪 **Test Behavior** | Test what the system does, not how it does it |
| 📦 **Small PRs** | Focused, reviewable, fast-to-merge changes |
